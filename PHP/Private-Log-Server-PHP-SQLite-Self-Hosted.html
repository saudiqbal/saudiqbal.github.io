Private Log Server using PHP SQLite for Self Hosting

A private self hosted central log server for collecting logs from all sorts of different services using Webhook, curl, wget or Json. I am currently using it on a Raspberry Pi Zero 2W. The requirements are just a web server and SQLite extension. To add or remove external authentication for service calls edit passwords and server names in notification.php and notification-json.php files.

Quick Demo: Click on the table header row to expand or collapse all log details at once.

Examples for inserting logs into Database

To receive notifications from Proxmox server use this as an example
Add a secret: Key = apikey, password = YourPassword
Method/URL: https://example.com/LogServer/notification-json.php
Body
{
"token": "{{ secrets.apikey }}",
"title": "{{ escape title }}",
"message": "{{ escape message }}",
"priority": "{{ severity }}"
}

Curl Example

curl -sSG --max-time 5 "https://example.com/LogServer/notification.php?token=NloqYbEIS14h" --data-urlencode "title=Proxmox VM 102" --data-urlencode "message=Proxmox VM 102 Started"Copy

To receive notifications as a Gotify server set an alias in your Apache or Nginx config. Example for Apache server Alias /LogServer/gotify/message /var/www/html/LogServer/gotify/gotify.php

You can omit the priority or add it using numbers from 1 to 10 which matches Proxmox or using the keywords - info, warning or error.

Curl Example with priority

Wget Example with priority

Database Pruning And Maintenance

Prune old or unwanted data logs by using a cron job to run scheduled maintenance. Example cron to keep the last 25000 records and delete the rest: 0 0 * * * /usr/bin/php /var/www/html/LogServer/delete-old-records.phpCopy
