Private Log Server using PHP SQLite for Self Hosting

A self hosted central log server for collecting logs from all sorts of different services using Webhook, curl, wget or Json. Click on the table title to expand or collapse all log details at once. To add or remove external authentication for service calls edit passwords and server names in notification.php and notification-json.php files.

You can omit the priority or add it using numbers from 1 to 10 which matches Proxmox or using the keywords - info, warning or error.

To receive notifications as a Gotify server set an alias in your Apache or Nginx config. Example for Apache server Alias /LogServer/gotify/message /var/www/html/LogServer/gotify/gotify.php

To receive notifications from Proxmox server use this as an example
Add a secret: Key = apikey, password = YourPassword
Method/URL: https://example.com/LogServer/notification-json.php
Body
{
"token": "{{ secrets.apikey }}",
"title": "{{ escape title }}",
"message": "{{ escape message }}",
"priority": "{{ severity }}"
}

Curl Example

Wget Example

Database Pruning And Maintenance

Prune old or unwanted data by using a cron job to run scheduled maintenance. Example cron to keep the last 25000 records and delete the rest: 0 0 * * * /usr/bin/php /var/www/html/LogServer/delete-old-records.phpCopy
